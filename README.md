# Minecraft 服务器监控插件 Plus

面向 AstrBot 的 Minecraft 服务器状态监控插件：支持为多个 QQ 群分别配置服务器，定时检查状态变化并发送通知，同时生成最近 24 小时的在线人数统计图。

[![AI Assisted](https://img.shields.io/badge/AI-GPT%20Assisted-10A37F?style=flat-square&logo=openai&logoColor=white)](#致谢与许可)

| 项目 | 要求 |
| --- | --- |
| 当前版本 | `v1.2.0` |
| AstrBot | `>=4.26.0` |
| 主要适配平台 | `aiocqhttp` |

完整版本记录见 [CHANGELOG.md](https://github.com/shenbimicro233/astrbot_plugin_apimcmc/blob/master/CHANGELOG.md)。

## 功能

- 多群独立配置：服务器地址、类型、查询源与通知格式互不影响
- 支持 Java 版与基岩版；Java 版支持 DNS SRV 解析（适用于所有查询源）
- 查询源可选 `mcstatus.io`、`mcmotdapi` 或本地直连，每群可继承全局设置
- 仅在首次检测、服务器上下线或在线人数变化时发送通知
- 通知格式支持完整、精简、自定义三种，WebUI 实时预览
- 群成员可随时查询服务器状态，或查看最近 24 小时在线人数统计图
- WebUI 支持配置搜索、状态筛选、日志查看，并自动跟随 AstrBot 深色/浅色主题

## 快速开始

1. 在 AstrBot WebUI 中安装并启用插件，运行依赖会自动安装。
2. 打开「插件配置」，设置检查间隔、是否自动启动监控以及默认查询源。
3. 在插件页「Minecraft服务器监控」点击「添加配置」，填写群号、服务器 IP、端口和服务器类型；「服务器类型」下拉框直接包含 Java 版（启用 / 禁用 SRV 解析）两态，选择「启用 SRV 解析」时端口可留空。
4. 保存配置。若未开启「自动启动监控」，发送 `/start_server_monitor` 手动启动。

## 配置

配置分为全局「插件配置」和插件页中的每群配置，表中名称与 WebUI 显示一致。

### 全局插件配置

| WebUI 选项 | 作用 | 默认值 |
| --- | --- | --- |
| 检查间隔（秒） | 所有已配置服务器的检查频率 | `10`（建议 10–60） |
| 自动启动监控 | 插件加载后自动启动所有已启用群的监控 | 关闭 |
| API查询源 | 默认查询服务 | 本地直连 |
| mcmotdapi 服务地址 / 启用 HTTPS | 使用 `mcmotdapi` 时的连接设置 | `motd.minebbs.com` / 开启 |
| 简化消息格式 | 每群未单独指定时默认使用简短通知 | 关闭 |
| 统计图文字样式 / 备用字体候选 | 图表字体样式与系统回退字体 | 普通中文（Fusion Pixel）/ 留空 |

### 每群配置

| WebUI 选项 | 说明 |
| --- | --- |
| QQ 群号 | 必填，接收通知并使用群指令 |
| 服务器名称 | 默认「Minecraft服务器」；统计图不显示 |
| 服务器 IP | 必填 |
| 端口 | 默认 `19132`；选择「Java 版（启用 SRV 解析）」时可留空 |
| 服务器类型 | 基岩版 / Java 版（启用 / 禁用 SRV 解析），默认基岩版；SRV 策略由每群显式决定 |
| API 查询源 | 全局默认 / `mcstatus.io` / `mcmotdapi` / 本地直连，默认继承全局 |
| 启用监控 | 是否参与定时检查，默认开启 |
| mcmotdapi 服务地址 / 启用 HTTPS | 仅使用 `mcmotdapi` 时显示，留空继承全局 |
| 消息格式 | 完整 / 精简 / 自定义，默认完整 |

「自定义」消息可勾选：`在线状态图标`、`服务器名称`、`MOTD 描述`、`游戏版本`、`协议版本`、`在线/最大玩家`、`服务端软件`、`服务器类型`、`地图名称`、`更新时间`、`附加一言`。字段顺序固定，WebUI 会实时预览。

## 指令

| 指令 | 权限 | 作用 |
| --- | --- | --- |
| `/start_server_monitor` | 管理员 | 启动全局监控，检查所有已启用且配置完整的群 |
| `/stop_server_monitor` | 管理员 | 停止全局监控 |
| `/查询` | 群成员 | 立即查询当前群服务器状态（仅群聊） |
| `/在线统计` | 群成员 | 返回最近 24 小时在线人数统计图（仅群聊） |
| `/重置监控` | 管理员 | 清除当前群状态缓存，下次检查按首次检测处理 |

## 通知格式

| 格式 | 内容 | 一言 |
| --- | --- | --- |
| 完整 | 状态变化、MOTD、版本、在线人数等完整信息 | 默认附带 |
| 精简 | 状态变化、服务器名称与在线人数摘要 | 不附带 |
| 自定义 | 仅显示 WebUI 中勾选的字段 | 勾选「附加一言」时附带 |

每群选择的格式优先于全局「简化消息格式」。

## 监控与在线统计

- 全局监控任务会并发检查所有已启用且配置完整的群；首次成功检查发送初始状态，之后仅在上下线或人数变化时通知。
- 玩家变动只报告有玩家上线/下线，所有查询源均不解析或展示玩家名单。
- `/查询` 会立即请求状态，但不替代定时监控；`/在线统计` 复用监控数据，不额外请求服务器或 API。
- 每 15 分钟保留第一次成功观测，滚动窗口最多 96 个观测点；失败请求记为缺失（红色半透明遮罩），不算离线；成功查询到离线时人数记为 `0`，图表不会跨越缺失时段连线。
- 连续无缺口离线至少 30 分钟后，图表显示离线遮罩；在线但零人不会触发。
- 纵轴从 `0` 开始，以窗口内可见观测的最高人数为上限（全零时用 `1`）。
- 更换服务器会开始新的 24 小时统计序列；数据保存在插件数据目录，更新、重载或重启不丢失，临时统计图会自动清理。

## 查询源

| 查询源 | 说明 | 默认地址 |
| --- | --- | --- |
| `mcstatus.io` | 公共状态查询接口；Java 版 SRV 由服务端自动处理，插件无法关闭 | `api.mcstatus.io` |
| `mcmotdapi` | 公共实例或自部署服务；Java SRV 由插件控制（启用 `srv=true`，禁用 `srv=false`） | `motd.minebbs.com` |
| 本地直连 | 机器人主机直接查询；启用时优先解析 `_minecraft._tcp` SRV 记录，失败回退配置端口或 `25565` | 无 |

- 每群选择「全局默认」时继承全局查询源及相关连接设置。
- Java 版 SRV 策略由每个群在「服务器类型」中显式选择（启用 / 禁用），适用于所有查询源；基岩版不使用 SRV。
- 本地直连需机器人主机能访问目标端口（Java 通常为 TCP `25565`，基岩版为 UDP `19132`）。云服务器、容器或 NAT 环境可能无法直连内网服务器，请改用 API 查询源。

## 注意事项

- 插件需要能访问所选查询服务；带一言的通知还需要访问一言服务。
- 使用自部署 `mcmotdapi` 时，请确认服务地址、HTTPS 设置与网络连通性。
- 机器人需已加入目标群并拥有发言权限；主动通知需要群内至少收到过一条消息。
- `/查询`、`/在线统计` 仅在已添加服务器配置的群可用；`/在线统计` 需监控至少成功查询一次。
- 依赖由 AstrBot 自动安装；若失败，请检查平台日志中的网络、镜像与权限错误。
- 公共查询源可能存在服务端/CDN 缓存，人数变化通知可能存在延迟，属正常现象,推荐优先使用本地存储的方式查询。

## 常见问题

- **自动监控没有启动**：确认全局「自动启动监控」已开启、群配置完整且端口已填写（明确启用 SRV 解析的 Java 配置除外），或发送 `/start_server_monitor` 手动启动。
- **`/在线统计` 没有返回图片**：确认当前群已添加配置，并让监控至少成功查询一次。
- **精简通知没有一言**：这是预期行为；如需保留一言，请选择「自定义」并勾选「附加一言」。
- **消息没有发送到群里**：检查群号、「启用监控」开关、机器人发言权限和监控任务状态。
