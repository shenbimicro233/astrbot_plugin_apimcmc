# Minecraft服务器监控插件

这是一个基于 AstrBot 框架开发的 Minecraft 服务器监控插件，支持为多个 QQ 群独立配置服务器，并定时检测状态变化后自动发送通知。\
本插件在原作者 [cryfly666](https://github.com/cryfly666) 的基础上重构，并围绕多群配置、消息格式和 WebUI 管理能力做了持续增强。

[![AI Assisted](https://img.shields.io/badge/AI-GPT%20Assisted-10A37F?style=for-the-badge&logo=openai&logoColor=white)](#ai-制作声明)

**AI 制作声明**：本插件的部分代码由生成式 AI 协助完成，所有内容经仓库维护者审阅。


## 功能特性

- **多群独立监控**：每个 QQ 群可独立配置服务器地址、端口、类型、消息格式和 API 源
- **Java / Bedrock 双版本支持**：通过 `server_type` 指定服务器类型
- **多 API 源支持**：支持 `mcstatus.io` 和 `mcmotdapi`，可全局或按群切换，并可单独配置 `mcmotdapi` 地址与 HTTPS
- **自定义服务器名称**：可为每个群设置展示名称，消息中不再直接暴露原始地址
- **三种消息格式**：支持完整、精简、自定义三种模式；自定义模式可按字段勾选显示内容
- **实时消息预览**：WebUI 中切换消息格式和自定义字段时可实时预览效果
- **定时变化检测**：仅在首次检测、服务器上下线、玩家加入或离开时发送通知
- **查询结果显示实际 API 源**：手动 `/查询` 时会标明当前实际使用的接口来源
- **独立运行日志**：WebUI 可查看监控状态、最近检查时间、运行日志，并支持搜索、仅看错误、自动刷新和清空
- **一言按模式控制**：完整模式默认附带一言，精简模式不附带；自定义模式下可单独勾选是否显示

## 首次使用
1. 安装插件后，先在 AstrBot WebUI 的「插件配置」中设置全局参数。
2. 如果你希望插件加载后自动开始轮询，可开启 `enable_auto_monitor`；否则可稍后用命令手动启动。
3. 进入插件页「Minecraft服务器监控」添加每个群的服务器配置。
4. 根据需要为每个群设置 API 源、消息格式和自定义字段。
5. 保存后配置会立即生效；已开启自动监控时会直接进入轮询。

## 配置说明

插件配置分为**全局配置**和**每群配置**两部分。

### 全局配置

在 AstrBot WebUI「插件配置」中设置：

| 配置键 | 中文名称 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- | --- |
| `check_interval` | 监控检查间隔 | 监控任务的轮询间隔，单位为秒 | 整数 | 10 |
| `enable_auto_monitor` | 自动启动监控 | 插件加载后是否自动启动全局监控任务 | 布尔值 | false |
| `api_source` | API 查询源 | 查询服务器状态时使用的接口源：`mcstatus` 或 `mcmotdapi` | 字符串 | mcstatus |
| `mcmotdapi_host` | mcmotdapi 服务地址 | 选择 `mcmotdapi` 作为查询源时使用的服务域名或地址 | 字符串 | motd.minebbs.com |
| `mcmotdapi_ssl` | mcmotdapi HTTPS 开关 | 选择 `mcmotdapi` 作为查询源时是否启用 HTTPS | 布尔值 | true |
| `simple_mode` | 默认精简消息格式 | 作为全局默认消息模式；每群未单独设置时生效 | 布尔值 | false |

### 每群配置

在 AstrBot WebUI「插件页」→「Minecraft服务器监控」中管理，每个群包含以下字段：

| 配置键 | 中文名称 | 说明 | 类型 | 默认值 | 必填 |
| --- | --- | --- | --- | --- | --- |
| `group_id` | QQ 群号 | 要接收监控通知的 QQ 群号 | 字符串/数字 | - | ✅ |
| `name` | 服务器显示名称 | 消息中展示的服务器名称；留空时使用默认名称 | 字符串 | "Minecraft服务器" | ❌ |
| `server_ip` | 服务器地址 | Minecraft 服务器的 IP 或域名 | 字符串 | - | ✅ |
| `server_port` | 服务器端口 | Minecraft 服务器的监听端口 | 整数 | 19132 | ✅ |
| `server_type` | 服务器类型 | 服务器版本类型：`java` 或 `bedrock` | 字符串 | bedrock | ✅ |
| `enabled` | 启用监控 | 是否启用该群的监控任务 | 布尔值 | true | ❌ |
| `api_source` | API 查询源 | 当前群专用查询源；留空时继承全局配置 | 字符串 | 空（全局默认） | ❌ |
| `mcmotdapi_host` | mcmotdapi 服务地址 | 当前群专用的 mcmotdapi 地址；留空时继承全局配置 | 字符串 | 空（全局默认） | ❌ |
| `mcmotdapi_ssl` | mcmotdapi HTTPS 开关 | 当前群是否对 mcmotdapi 启用 HTTPS；未设置时继承全局配置 | 布尔值 | 未设置（全局默认） | ❌ |
| `simple_mode` | 精简消息格式 | 当前群是否使用精简摘要；在 WebUI 里对应“精简”模式 | 布尔值 | 未设置（继承全局默认） | ❌ |
| `custom_mode` | 自定义消息格式 | 当前群是否启用自定义字段模式；启用后优先级高于 `simple_mode` | 布尔值 | 未设置 | ❌ |
| `custom_fields` | 自定义显示字段 | 自定义模式下要显示的字段列表，如 `name`、`player_count`、`motd`、`hitokoto` | 数组 | 未设置 | ❌ |

`custom_fields` 当前支持以下字段键：

| 字段键 | 中文名称 | 说明 |
| --- | --- | --- |
| `status_emoji` | 在线状态图标 | 显示在线/离线状态图标 |
| `name` | 服务器名称 | 显示配置中的服务器名称 |
| `motd` | MOTD 描述 | 显示服务器 MOTD |
| `version` | 游戏版本 | 显示 Minecraft 版本信息 |
| `protocol` | 协议版本 | 显示协议号 |
| `player_count` | 在线/最大玩家 | 显示当前在线人数和最大人数 |
| `player_list` | 玩家列表 | 显示在线玩家名称列表 |
| `software` | 服务端软件 | 显示 Paper、Spigot 等服务端软件信息 |
| `type_label` | 服务器类型 | 显示 Java 版或基岩版 |
| `map` | 地图名称 | 显示服务器地图名称 |
| `update_time` | 更新时间 | 显示最近一次状态更新时间 |
| `hitokoto` | 附加一言 | 在消息末尾追加一言内容 |

## 可用指令

| 指令 | 中文含义 | 权限 | 使用场景 |
| --- | --- | --- | --- |
| `/start_server_monitor` | 启动服务器监控 | 管理员 | 启动全局定时监控任务，所有已启用且配置完整的群都会被轮询 |
| `/stop_server_monitor` | 停止服务器监控 | 管理员 | 停止全局定时监控任务 |
| `/查询` | 查询当前服务器状态 | 群成员 | 立即查询当前群配置的服务器状态，仅在群聊中可用 |
| `/重置监控` | 重置当前群监控状态 | 管理员 | 清空当前群的状态缓存，下次检测视为首次检测 |

## 监控逻辑

1. 插件启动后会加载所有已保存的群配置。
2. 调用 `/start_server_monitor` 或在全局配置中开启 `enable_auto_monitor` 后，监控任务开始运行。
3. 每个检查周期内，插件会并发查询所有已启用群对应的服务器状态。
4. 使用每群独立的状态缓存（`ChangeTracker`）对比前后两次数据，仅在以下情况发送通知：
   - 首次检测到服务器状态
   - 服务器上线或离线
   - 有玩家加入或离开

## 通知消息格式

插件当前支持三种消息格式：

### 1. 完整模式

用于展示完整状态信息，适合人数较少或更关注详细内容的群。

检测到变化时，机器人会向对应群发送类似消息：

```
🔔 服务器状态变化：
[变化描述]

📊 当前状态：
🟢 服务器: [名称]
📝 MOTD: [服务器MOTD]
🎮 版本: [版本]
👥 在线玩家: [当前]/[最大]
📋 玩家列表: [玩家1, 玩家2, ...]
🔧 类型: [Java版/基岩版]
🕒 更新时间: [时间]

💬 [一言句子]
```

完整模式下，消息末尾会自动附带一言。

### 2. 精简模式

精简模式只保留核心摘要，适合大型服务器或不希望频繁刷屏的群：

```
🔔 服务器状态变化：[变化描述]

🟢 [服务器名]  👥 [当前]/[最大]
```

精简模式**不附带一言**。

### 3. 自定义模式

自定义模式可在 WebUI 里自由勾选字段，并实时查看预览。字段显示顺序固定为：

`状态图标 -> 名称 -> MOTD -> 版本 -> 协议 -> 在线人数 -> 玩家列表 -> 软件 -> 类型 -> 地图 -> 更新时间 -> 一言`

如果你在自定义字段里勾选了 `hitokoto`，消息末尾才会附带一言。

## WebUI 功能

插件在 AstrBot WebUI 中提供以下能力，便于管理和排障：

- 查看统计卡片：总配置数、已启用数量、Java/Bedrock 数量、监控状态
- 查看/新增/更新/删除群配置
- 按群号、名称、IP 搜索配置，并按启用状态和服务器类型筛选
- 为每个群单独设置 API 源、`mcmotdapi` 地址与 HTTPS 开关
- 切换完整 / 精简 / 自定义消息格式，并实时预览消息内容
- 查看监控运行状态、最近检查时间、最近变更时间等信息
- 查看运行日志，并支持自动刷新、仅显示错误、关键字搜索、清空日志

## 数据来源

插件支持以下 API 查询源，可通过全局配置或每群配置切换：

| 源标识 | 中文名称 | 说明 | 默认地址 |
| --- | --- | --- | --- |
| `mcstatus` | mcstatus 公共接口 | [mcstatus.io](https://api.mcstatus.io/v2/status) 提供的公共 API，无需自部署 | `api.mcstatus.io` |
| `mcmotdapi` | mcmotdapi 接口 | [mcmotdapi](https://github.com/mcmotd/mcmotdapi) 自部署服务，也可使用公共实例 | `motd.minebbs.com`（默认） |

**生效优先级**：

1. 每群配置优先于全局配置
2. `custom_mode = true` 时优先使用自定义消息格式
3. 未启用自定义模式时，才根据 `simple_mode` 决定使用精简模式还是完整模式

## 注意事项

- ⚠️ 插件需要能访问外网以调用 `mcstatus.io` API / `mcmotdapi` 服务 / 一言 API
- ⚠️ 使用 mcmotdapi 源时，请确保自部署服务可访问，或使用默认公共实例 `motd.minebbs.com`
- ⚠️ 当前版本主要适配 `aiocqhttp` 平台，请确保机器人已在目标 QQ 群中
- ⚠️ 建议将 `check_interval` 设置为 10~60 秒，避免过于频繁的请求
- ⚠️ 只有在 WebUI 中为当前群添加了配置，`/查询` 和监控通知才能正常工作
- ⚠️ `/start_server_monitor` 启动的是全局任务，单个群可通过 `enabled` 开关控制是否参与监控
- ⚠️ `/查询` 只允许在群聊中使用；`/start_server_monitor`、`/stop_server_monitor`、`/重置监控` 需要管理员权限
- ⚠️ 自定义消息格式未勾选任何字段时，不会生成有效内容，建议至少勾选 `name`、`player_count` 等核心字段

## 常见问题

**Q: 为什么自动监控没有启动？**\
A: 检查全局配置中 `enable_auto_monitor` 是否为 `true`，以及是否至少有一个已启用且填写了 `group_id`、`server_ip`、`server_port` 的群配置。

**Q: `/查询` 提示当前群未配置监控？**\
A: 需要先在 WebUI「Minecraft服务器监控」页面添加该群的配置。

**Q: 为什么我已经开了精简模式，却没有一言？**\
A: 这是当前设计。完整模式默认附带一言，精简模式不附带；如果你希望精简内容中保留一言，可以改用自定义模式并勾选 `hitokoto`。

**Q: 自定义模式和精简模式同时设置时，哪个生效？**\
A: 自定义模式优先级更高。只要 `custom_mode = true` 且选择了字段，就会按自定义字段生成消息。

**Q: 如何清除某个群的监控状态？**\
A: 在该群中发送 `/重置监控`，该群的状态缓存会被重置，下次检测视为首次检测。

**Q: 消息没有发送到群里？**\
A: 检查群号是否正确、该群配置是否启用、机器人是否有发送权限，以及该群是否触发过任意一条消息以让插件缓存会话信息。
